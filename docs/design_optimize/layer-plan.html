同水彩纹理内		真实数据折线的「生硬描边感」设计稿为手绘毛边、token 边界为更细的墨线边界/干边改设计墨色 #3A3428，描边加 setLineDash 断续 + 1px 微抖动（bump 采样），仍走真实折线数据手绘般的干笔毛边待做

LabelLayer（Compose Canvas）		早期为米白圆角卡片 UI 感与水墨冲突撤卡片：深墨字直书 + 1.2px 纸色 halo 双 pass；城市画「墨点+纸色细环」靶心；rank≤2 州府加大字手写批注语言R6 已做
9 年份水印
Compose Text（标签之下、泡泡之下）		120px 衬线、墨色 α26，位置 57.9% 宽与设计一致无改动（已 token 化）淡墨水印不遮挡叙事已对齐
10 事件点/指向线/泡泡
EventBubblesLayer（Compose Canvas）		普通=标题+年份、选中=+两行摘要、聚合=+N；虚线指向线+箭头+事件点靶心泡泡未带设计卡片阴影/朱砂描边分层绘制按 token 补：阴影层(α35/3px) → 纸面(α238) → 朱砂描边(1px) → 分类竖条(6px) → 文字；安全区回收不变纸笺式泡泡细节打磨
11 顶栏/图例/时间轴
Compose（Surface + Canvas）		朝代按钮朱砂印章式、图例折叠小笺、时间轴三行布局与设计一致，个别字号偏差已登记无结构性改动；字号/间距走 token—已对齐

原则：分层结构不动（GL 四 quad + Compose 上层），所有修改都是某一层的绘制参数或细节；河流若要细分主/次开关、州府若要独立开关，也只按「山脉/河流」的既有模式新增纹理槽。

FLOW 描画流程（一次朝代加载）

① 数据进包scripts/prepare-android.mjs同步 seed SQL + GeoJSON（regime/rivers/mountains/prefectures）到 assets/
→
② 解析OverlayLoader（org.json 复刻 overlay.js 合并）→ OverlayParser 产出 OverlayModel
→
③ 装配MapRenderer.setOverlay()投影标定（仅一次）+ labels/regimeColors/worldBounds + resetCamera（地图区 ×1.4，水平锚定宋域）
→
④ CPU 纹理buildTextures() 放 Dispatchers.IO：烘焙贴图优先 → 程序化 WatercolorBuilder + TerrainTextureBuilder（山/河两图），LRU 缓存
→
⑤ GL 每帧onDrawFrame() 懒上传 → 纸 → 山 → 水彩 → 河；时期切换交叉淡入 350ms（旧→prev 淡出/新淡入）
→
⑥ Compose 每帧相机状态 zoom/cx/cy → worldToScreen → layoutMapLabels 避让（政权面+UI 禁区）→ LabelLayer；TimelineController 年份 → 可见事件 → Collisions 推挤 → EventBubblesLayer

线程模型：UI 线程写数据/相机状态；GL 线程每帧读 @Volatile 引用画底图；Compose 状态（zoom/cx/cy/年份）驱动上层标签与泡泡重算。P20 实测 55–59fps。
