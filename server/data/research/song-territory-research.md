## 一、两宋疆域总览

| 时期 | 时间 | 最大面积 | 边界描述 |
|---|---|---|---|
| **北宋** | 960–1127 | 约 280–310 万 km² | 北：海河—雁门关—横山；西北：河西走廊东端；西：青藏高原东缘；南：南海 |
| **南宋** | 1127–1279 | 约 180–210 万 km² | 北：秦岭—淮河一线；西：大渡河（大理界）；南：南海 |

### 核心疆域 evolution

```
北宋（960） → 中原偏小
北宋（980） → 统一中原 + 南方，约 310 万 km²  ← 最大版图
北宋（1111）→ 稳定期，约 280 万 km²
北宋（1125）→ 海上之盟灭辽后短暂收燕云
南宋（1127）→ 退守淮河以南，约 210 万 km²
南宋（1142）→ 绍兴和议固定边界，约 200 万 km²
南宋（1204）→ 约 180 万 km²
南宋（1276）→ 临安陷落，仅剩闽广沿海
南宋（1279）→ 崖山海战，灭亡
```

### 2.2 北宋北界（宋辽边界）

**条约依据**：澶渊之盟（1005 年）

**边界走向**（自东向西）：
1. **东段**：白沟河（今海河支流）—— 河北平原
   - 宋方：雄州（今雄安新区）、霸州、容城
   - 辽方：南京道（今北京）
   - 宋在河北平原种植**榆柳林带**作为骑兵屏障（"榆塞"）
2. **中段**：雁门山—恒山山脉
   - 宋方：代州（雁门关）、应州
   - 辽方：西京道（大同）
3. **西段**：管涔山—黄河

## 八、地图绘制技术建议

### 8.1 当前基础地图

`server/data/geo/china.json` 是**现代中国省级行政区划** GeoJSON，包含 35 个省份/自治区/直辖市的多边形数据。

### 8.2 绘制方案

我们有三个选择：

**方案 A：用现代地图裁剪（推荐首期）**
- 利用现有 china.json，在渲染时**用颜色/半透明蒙版标记**宋的实际控制范围
- 比如：将北宋控制区内的省份上色，非控制区灰色
- 优点：不用改现有代码，快速实现；AGENTS.md 已声明"基础地图静态托管"
- 缺点：边界精度不高（以省为单位，不是精确的历史边界）

**方案 B：绘制精确历史边界（扩展期）**
- 为宋、辽、西夏分别制作**简化的历史边界 Polygon** 存为独立的 GeoJSON
- 文件提议：
  - `server/data/geo/song-northern.json` — 北宋边界（约 1111 年）
  - `server/data/geo/song-southern.json` — 南宋边界（约 1142 年）
  - `server/data/geo/liao.json` — 辽边界
  - `server/data/geo/western-xia.json` — 西夏边界
  - `server/data/geo/jin.json` — 金边界
- 优点：精确美观；缺点：需手工制作或从公开数据转换

**方案 C：混合（推荐）**
- 用现代中国地图作为底图（保持现有 `GET /api/map` 不变）
- 新增 `GET /api/map/overlay` 返回历史时期边界（多边形）
- 在 three.js 中用不同颜色渲染边界叠加层

### 8.3 overlay 扩展接口设计

按 `AGENTS.md` 已有预留：

```
GET /api/map/overlay?dynasty=song&period=1111
```

返回格式：
```json
{
  "type": "FeatureCollection",
  "features": [
    {
      "type": "Feature",
      "properties": {
        "name": "北宋",
        "color": "#ff0000",
        "opacity": 0.3
      },
      "geometry": {
        "type": "Polygon",
        "coordinates": [[[lng, lat], ...]]
      }
    },
    {
      "type": "Feature",
      "properties": {
        "name": "辽",
        "color": "#00ff00",
        "opacity": 0.3
      },
      "geometry": { ... }
    },
    {
      "type": "Feature",
      "properties": {
        "name": "西夏",
        "color": "#0000ff",
        "opacity": 0.3
      },
      "geometry": { ... }
    }
  ]
}
```
